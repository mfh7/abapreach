Usage: abapreach create [OPTIONS] --conn <CONN> <KIND> <NAME> [FILE]

Arguments:
  <KIND>  [possible values: PROG, FUGR, FUNC, CLAS, INTF, DTEL, DOMA, TABL, TTYP, TRAN]
  <NAME>  
  [FILE]  A `PROG` create only: the source a simulate deploy checks after `CREATE: ACTIVE`

Options:
      --text <TEXT>        Required except for DTEL, DOMA, TABL and TTYP, whose description is in the XML file
      --package <PACKAGE>  
      --fugr <FUGR>        
      --prog <PROG>        A `TRAN` create only: the report the transaction starts
      --subc <SUBC>        A `PROG` create only: `1` for a program (the default) or `I` for an include [possible values: 1, I]
      --tr <TR>            
      --simulate           For DTEL, DOMA, TABL, TTYP and TRAN a simulate still creates and deletes a temporary class in $TMP
      --backend <BACKEND>  [possible values: adt, rfc]
      --conn <CONN>        
  -h, --help               Print help
